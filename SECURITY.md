# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | ✅ |
| < 1.0   | ❌ |

## Reporting a vulnerability

Do **not** open public issues for security bugs.

Email: **security@mcp-hub.example**

Please include:
- Vulnerability type and impact
- Reproduction steps / proof of concept
- Affected versions or commit hashes
- Any suggested mitigation

## Response targets

- Initial acknowledgement: within 3 business days
- Triage decision: within 7 business days
- Fix timeline: depends on severity and complexity

## Security update policy

Critical and high-severity vulnerabilities are prioritized and patched first.
Security fixes may be released outside normal release cadence.

## Disclosure policy

We follow coordinated disclosure:
1. Reporter submits details privately.
2. Maintainers validate and patch.
3. Coordinated public advisory is published after fix release.

## Bug bounty

No formal bug bounty program currently.
