Welcome to MCP Hub — your mobile-first control center for the Model Context Protocol. MCP Hub lets you connect to any MCP server, discover the tools it exposes, execute them with dynamically generated forms, record macro sequences, and automate full workflows, all from a single interface that runs on iOS, Android, and the web.

## What is MCP Hub?

MCP Hub is built around three core pillars that take you from raw MCP server connections all the way to production-grade automation.

**Server Connections** — MCP Hub manages the full lifecycle of your MCP server connections. Add servers by URL or stdio command, connect and disconnect on demand, and monitor health with built-in ping checks. All connection state is persisted so your servers are ready the moment you open the app.

**Tool Execution** — Once a server is connected, MCP Hub runs `tools/list` to enumerate every tool the server exposes and renders a dynamic form for each one based on its JSON Schema input definition. Fill in the fields, tap Execute, and see structured results instantly — no code required.

**Automation and Macros** — Record a sequence of tool calls as a macro and replay it with a single tap. Chain macros and individual tool calls into scheduled workflows for end-to-end automation. Every execution is logged in a full audit history with request and response payloads.
