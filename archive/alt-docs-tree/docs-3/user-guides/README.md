# User Guides

## Connect an MCP server

1. Open the server connection screen.
2. Enter server endpoint and credentials.
3. Save as preset for reuse.
4. Validate health and tool discovery.

## Execute tools

1. Discover tools from connected server.
2. Select tool and fill input payload.
3. Run execution and inspect result view.
4. Save reusable patterns as macros.

## Manage macros

- Create and edit chained workflows
- Schedule runs for recurring tasks
- Share with permission controls
- Track execution history and outcomes

## Troubleshooting

- Verify server URL and auth credentials
- Check execution history for structured errors
- Confirm server supports requested MCP tool interfaces
