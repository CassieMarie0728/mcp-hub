| Term | Definition |
| --- | --- |
| MCP | Model Context Protocol — the spec for apps to discover and call tools on remote servers. This project implements protocol version `2024-11-25`. |
| MCP client | The party that connects to a server and calls its tools. Here: `server/mcp/mcp-server-manager.ts` + `lib/mcp-client.ts`. |
| MCP server | A program exposing tools (GitHub, Slack, Notion, or any custom HTTP server). |
| Tool | A named, typed capability on a server, called with a JSON argument object. |
| Transport | How client and server communicate. HTTP is implemented; stdio/SSE/WebSocket exist in code but are not fully wired. |
| JSON-RPC | The request/response message format MCP is built on (version 2.0). |
| Protocol version | The MCP spec revision a client/server negotiates; `2024-11-25` here. |
| tRPC | The typed-RPC layer between the Expo app and Express backend (`server/routers.ts`, 10 routers). |
| Router | A named group of tRPC procedures, e.g. `mcp`, `tokens`, `webhooks`. |
| Procedure | A single query or mutation in a router. |
| Session cookie | `app_session_id` — the browser/mobile cookie carrying the signed session JWT. |
| JWT | JSON Web Token; the signed credential inside the session cookie (jose library). |
| OAuth | Authorization flow for preset integrations; `server/auth/oauth-router.ts`. |
| Preset | A pre-built MCP server definition: GitHub, Slack, Notion. |
| In-memory store | A `Map`-based store that resets on restart (macros, workflows, webhooks, analytics, server registry). |
| Macro | A saved sequence of tool calls you can re-run (`lib/engines/MacroExecutionEngine.ts`). |
| Workflow | A multi-step automation script over tools; in-memory (`server/procedures/workflows.ts`). |
| Template | A starting shape for workflows/macros (`server/templates/`). |
| Webhook | An outbound HTTP callback a server sends on an event (`server/webhooks/`). |
| Token | A stored credential for a server, managed via the `tokens` router. |
| Disabled feature | Code present but not routed/registered (screens under `app/_disabled/`); not user-facing. |
| Drizzle ORM | The TypeScript ORM used for the `users` table and migrations. |
| Drizzle migration | Versioned schema change in `drizzle/`, generated by `drizzle-kit`. |
| Expo Router | File-based routing for the app (`app/` directory). |
| Metro | The bundler running the dev app (`dev:metro`, port 8081). |
| NativeWind | Tailwind-style styling for React Native (`nativewind` package). |
| Gateway | The backend entry that routes `/api/*` traffic (see note in `server/routers.ts`). |
